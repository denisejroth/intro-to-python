# Module 0 — Setting Up Python

How to get Python running on your own machine. Mostly **reference material** — for the course
itself, Colab is all you need.

**Slides:** Python 2 vs 3, ways to run Python, local install (python.org / Anaconda), editors &
IDEs (VS Code walkthrough), **virtual environments** (`venv`, `conda`, `requirements.txt`), and
**cloning repositories** from GitHub.

**Notebook:** a reference guide collecting all the setup commands in one place.
